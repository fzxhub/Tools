加载 Demo 数据

DBC 信号解析工具 · 使用帮助

本工具的所有解析都在浏览器本地完成，文件不会上传服务器。加载新数据会替换当前会话中的自定义信号、曲线、时间卡尺与回放状态，请先导出需要保留的 DBC。

1. 加载数据

  • 左侧「数据加载」可选择或拖入 DBC 数据库（.dbc，可省略）和总线日志（.asc / .blf / .trc），然后点击「解析并加载」。
  • 点击顶部「Demo」按钮可一键加载内置的 demo.dbc + demo.blf，包含 7 个报文、80 个信号、18,096 帧、100 秒数据，覆盖标准帧、扩展帧、CAN FD、大小端、有符号、缩放/偏移、枚举、MUX 等场景；其中 Fd64Array 为 64 字节 CAN FD 周期报文（100ms 周期），带 60 个信号。
  • 点击 Demo 前会弹出确认框，因为当前会话中的自定义信号和图表状态会丢失。

2. 按帧解码

  • 底部胶囊左侧显示总帧数、报文/信号数、CAN FD 帧数、已解码数、未定义 ID 与时长；右侧是「回到首页 / 上一页 / 下一页 / 去到尾页」按钮。
  • 顶部工具栏可按报文过滤、按 ID / 数据 / 信号名或值搜索；「展开全部信号」可展开每帧的解码值，「折叠全部信号」可收起。
  • 每个帧数据行采用胶囊外观；点击某一帧可展开/折叠信号明细，信号按「信号名称 / 物理数据 / 16进制原始数据 / 转换关系等式」顺序排列；「导出 CSV」会把当前筛选结果导出。

3. 左侧信号树

  • 搜索框支持按报文名、ID 或信号名过滤。
  • 在「回放报文」或「时序曲线」界面勾选信号，会同时显示到回放报文与时序曲线；取消勾选也会同步移除。「按帧解码」界面的勾选框不可点击。把信号从左侧拖到曲线区或回放区也能添加。信号前面的颜色块可点击切换曲线与卡片颜色，色块扩大了点击热区，也可用 Tab 聚焦后按 Enter/空格切换。
  • 侧栏底部的「导出 DBC」会保存当前会话（含新建/编辑信号）；「＋ 创建信号」可在当前会话中新增信号；「清空选择」可同时清空回放报文与时序曲线中已选择的信号。

4. 回放报文

  • 「停止」暂停并回到 0 秒；「播放/暂停」控制回放；速率下拉提供 0.05x ~ 16x 共 13 档。
  • 单个信号与整帧报文可同时拖入回放区固定显示：整帧报文块独占一行，独立信号卡片在其后横向排列。报文块按「时间 / ID / 报文名 / 原始数据」报文头 + 该帧全部信号卡片展示，块内信号卡片与独立信号卡片样式、功能相同，但不带删除 ×。悬浮控制条上的「列数」下拉可选择自动列数或固定 2~10 列，两类信号卡片同步按列对齐。拖动时间轴可定位到任意时刻；独立信号卡片与报文块右上角的 × 可分别移除。
  • 固定显示的信号卡片（含报文块内的信号卡片）右下角迷你图表均可点击切换「折线图 / 仪表盘 / 横向柱状图」三种外观：折线图只绘制到当前播放进度，后续线段随回放逐步显示；仪表盘与柱状图按当前值在最小~最大区间的位置展示。双击信号卡片的边框或留白可切换高亮模式，用信号颜色加粗描边与光晕提高注意力；再次双击取消。

5. 时序曲线

  • 勾选或拖拽左侧信号即可同时添加回放卡片与曲线；每条曲线会显示单位、最小值、最大值和平均值。
  • 「独立纵轴」让每个信号使用独立分带；「合并显示」把多个信号叠在同一坐标系；合并模式下可勾选「归一化」统一量纲。
  • 图像区右下角悬浮的放大镜 / 箭头 / 适应 / 清除图标按钮可放大、缩小、左移、右移时间轴、回到初始显示并清除时间卡尺；左移/右移按住可持续平移，滚轮也可缩放横轴，拖拽图形区可平移；「离散 / 平滑」切换可显示或隐藏每个 CAN 报文对应的数据点，离散模式下双击放置卡尺会自动吸附到附近最近的离散数据点；侧栏底部的「清空选择」同时移除回放与曲线中的信号。双击曲线可放置时间卡尺，最多两个，卡尺时间仍在图像右上角信息面板显示。

6. 主题与数据说明

  • 右上角主题按钮支持「系统 / 明亮 / 暗黑」，选择会本地保存，下次打开仍然生效。
  • 未定义 ID 的帧仍会显示原始数据，但不会解出信号；CAN FD 帧会标注 FD/BRS/ESI。
  • 自定义信号只存在于当前浏览器会话中，刷新页面前如需保留请点击「导出 DBC」。
