CAN 固件升级

在浏览器里为 Bugable CAN 适配器刷写固件，无需安装工具链。请先让设备进入 Boot 模式。

操作步骤

3 步完成
  1. 按住设备上的 Boot 按键（带外壳设备请用卡针），再通过 USB 连接到电脑。
  2. 插入后松开 Boot 按键，在下方选择要刷入的固件，点击「Connect and Update」。
  3. 等待刷写完成提示，重新插拔 USB 即可正常使用。

注意事项

请先阅读
  • Windows 上如果浏览器识别不到设备，请先安装 USB 驱动。
  • Linux 下需要配置 udev 规则，或以超级用户权限启动 Chrome。
  • CAN1 与 CAN2 固件不通用，请根据设备型号选择。
  • 型号中带 FD 字样仅表示模拟对象，不代表支持 CAN FD。
